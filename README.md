# Anatomy Flashcards

A flashcard website for the terms studied in my Anatomy Advanced class.

🔗 **Live site:** https://codepasky.github.io/anatomy/

## What's here
- **Chapters** — prefixes organized by textbook chapter, with a dropdown to jump straight to the exact prefixes assigned for each class date
- **General List** — location/direction, number/measurement, organ/structure, and suffix term sets

## How it works
Pure HTML/CSS/JS, no build step. Click a card to flip it, use the Next/Prev buttons or arrow keys to move through a deck, or jump to any card using the numbered dots.

## Files
- `index.html` — Chapters page (loads by default)
- `general.html` — General List page
